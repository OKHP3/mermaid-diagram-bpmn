## WHAT THIS PROMPT BUILDS

The existing app has six pages: Home, Playground, DSL Reference,
Architecture, Roadmap, About. This prompt adds a seventh: Agent Skills.

The Agent Skills page and its sub-components form a fully featured
browser and download portal for the BP-SKILL v0.3 suite — 15 SKILL.md
files, 9 variable layer templates, the Process Narrative Specification
(PNS) schema, and the eval suite — all embedded as static data and
downloadable as individual files or as a bundled zip.

The goal is to make the app serve three audiences simultaneously:

1. Human practitioners who want to understand what the suite does
1. Developers who want to install individual skills or the full suite
1. AI agents browsing the standards context and downloading skills

## PHASE 2 — DATA LAYER: SKILL REGISTRY

Before building any UI components, build the data layer.
All skill data is static — no network requests, no backend.
Create src/data/skills-registry.js (or .ts if the project uses TypeScript).

This file exports a single SKILLS constant — an array of 15 skill objects
plus supporting constants for the variable layer and PNS schema.

### Skill object schema (one per skill):

```js
{
  id: "process-intake-and-scope",       // matches directory name
  name: "process-intake-and-scope",     // agentskills.io spec name
  displayName: "Process Intake & Scope", // human-readable
  status: "core",                        // "core" | "recommended-extension"
  layer: 1,                              // 1 = Discovery, 2 = Narrative,
                                         // 3 = Visual/Decision, 4 = Operational
                                         // 5 = Governance, 6 = Publication
  layerLabel: "Discovery",
  pipelineOrder: 1,                      // 1–15, ordering in the pipeline
  description: "...",                    // ≤ 1024 chars — the SKILL.md description field
  purpose: "...",                        // 2–3 sentence prose purpose
  triggerPhrases: [                      // what the user says to activate it
    "document a process",
    "map a workflow",
    "define process scope"
  ],
  consumes: ["pir.yaml (optional)", "organization-profile.md"],
  produces: ["PNS.md [status: draft-intake]", "pir.yaml"],
  dependsOn: [],
  standardsRefs: [
    "BABOK v3 §3.1–3.4",
    "BPM CBOK v4.0 Phase 1",
    "APQC PCF v7.4"
  ],
  installCommand: "# In your agent's skills/ directory:\nmkdir process-intake-and-scope && ...",
  skillMdPreview: "---\nname: process-intake-and-scope\n...", // first 30 lines
  tags: ["discovery", "intake", "babok", "apqc"],
  compatibleWith: ["Claude Code", "OpenAI Codex", "GitHub Copilot",
                   "Gemini CLI", "Cursor", "VS Code"]
}
```
