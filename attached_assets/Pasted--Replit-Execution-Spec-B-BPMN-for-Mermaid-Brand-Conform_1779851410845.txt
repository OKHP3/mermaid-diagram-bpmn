# Replit Execution Spec B — BPMN for Mermaid

## Brand Conformance Realignment to the OverKill Hill P³ Forge Motif

**Repo:** OKHP3/mermaid-diagram-bpmn
**Replit project:** BPMN-for-Mermaid
**Document type:** Execution specification with file-level targets, exact values, acceptance criteria, and guardrails
**Mode:** Realignment. This app diverges from brand on 9 of 12 visual axes and must be conformed.
**Spec version:** 1.0

-----

## 1. Read this first. The goal in one paragraph.

This app and its sibling (Mermaid Theme Builder) were both built in Replit, separately, and they drifted apart visually. They are supposed to look like two tools from the same studio, both clearly descended from the OverKill Hill P³ website. Right now this app uses the wrong fonts, the wrong ink color, the wrong dark-mode palette, the wrong header color, and the wrong corner radius, and it emits diagrams in a generic blue that has nothing to do with the brand. Your job is to bring every one of those axes into exact alignment with the canonical definition, changing styling tokens and the font load only, without touching layout, component structure, or behavior. When you are done, a person looking at this app and the sibling app side by side should not be able to tell they were built in separate projects.

This is a token and font alignment exercise. It is not a redesign. Do not move elements, change spacing rhythm, restructure components, or add features.

## 5. The fix list. Current value, then required value. Exact.

Each item gives the current (wrong) state and the required (canonical) state. Under Path 1, items 2 to 8 are satisfied by adopting the shared token file; still verify them.

**1. Font load — `index.html`.**
Current: loads Fraunces and Inter.

```
https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@...&family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap
```

Required: drop Fraunces and Inter; load Alfa Slab One and DM Sans, keep JetBrains Mono. Replace the Google Fonts `<link href>` with exactly:

```
https://fonts.googleapis.com/css2?family=Alfa+Slab+One&family=DM+Sans:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap
```

Update the adjacent HTML comment to name Alfa Slab One (display), DM Sans (body), JetBrains Mono (code). Remove the Fraunces/Inter comment.

**2. Sans font token — `src/index.css`.**
Current: `--app-font-sans: 'Inter', system-ui, sans-serif;`
Required: `--app-font-sans: 'DM Sans', system-ui, sans-serif;`

**3. Display font token — `src/index.css`.**
Current: `--app-font-display: 'Fraunces', Georgia, serif;`
Required: `--app-font-display: 'Alfa Slab One', system-ui, sans-serif;`
Also remove any `font-serif` assumption on `h1, h2`. Headings use the display token (now Alfa Slab One), not a serif.

**4. Light background — `src/index.css`.**
Current: `--background: 40 24% 92%;` (warm field `#f0ece4`)
Required: `--background: 33 18% 94%;` (warm paper `#f0ebe5`)

**5. Light foreground / ink — `src/index.css`.**
Current: `--foreground: 28 45% 8%;` (espresso brown `#1d1108`)
Required: `--foreground: 222 47% 11%;` (deep navy `#0f172a`)

**6. Light card — `src/index.css`.**
Current: `--card: 42 50% 97%;` (`#faf7f1`)
Required: `--card: 34 35% 95%;` (`#f6f2ee`)
Apply the same correction to `--popover` if it mirrors `--card`.

**7. Dark-mode palette — `src/index.css`.**
Current: olive family, hue 88 (`--background: 88 18% 9%;`, `--card: 88 15% 13%;`, `--border: 88 12% 20%;`).
Required: copy the sibling’s slate-blue forge dark block wholesale. Do not recompute or invent values.

The derived `--radius-sm/md/lg/xl` calc chain stays as is; it keys off `--radius`.

Eyebrow (`.forge-eyebrow`), current: mono font, wide tracking (~0.2em).

**10. Mermaid output theme — `src/lib/bpmn-styles.ts`.**
The exported `MERMAID_FALLBACK_THEME` (currently around line 51) drives diagram colors when CSS variables are not resolvable, which is exactly the SVG export context where brand fidelity matters most. It currently ships generic values:

```ts
export const MERMAID_FALLBACK_THEME: BpmnThemeOptions = {
  lineColor: '#333333',
  mainBkg: '#ffffff',
  nodeBorder: '#999999',
  clusterBkg: '#efefef',
  textColor: '#333333',
  primaryColor: '#1890ff',
};
```

Required: replace with the canonical OverKill Hill P³ Mermaid set. The `BpmnThemeOptions` interface has six fields (lineColor, mainBkg, nodeBorder, clusterBkg, textColor, primaryColor); populate them exactly:

```ts
export const MERMAID_FALLBACK_THEME: BpmnThemeOptions = {
  lineColor: '#c46a2c',
  mainBkg: '#111827',
  nodeBorder: '#c46a2c',
  clusterBkg: '#0d1117',
  textColor: '#e5e7eb',
  primaryColor: '#111827',
};
```

Preferred: if the sibling repo is reachable, import `OKH_P3_MERMAID_THEME` from its `src/lib/palettes.ts` and map the six fields from it rather than hardcoding, so there is one shared definition. If not reachable, hardcode the six values above. Do not change the `BpmnThemeOptions` interface or the `getStyles` function or `LIGHT_THEME`.

**11. Default mode is light — `src/components/Layout.tsx` (lines 25 to 37).**
Current logic adds `.dark` when no `theme` key is stored and the OS prefers dark:

```ts
localStorage.getItem("theme") === "dark" ||
(!localStorage.getItem("theme") && window.matchMedia("(prefers-color-scheme: dark)").matches)
```

Required: when no preference is stored, resolve to light. Remove the `prefers-color-scheme` fallback from the unstored branch so the default is light regardless of OS. The user can still toggle to dark, and a stored `"dark"` preference must still be honored. Net effect: first visit with no stored preference renders light.

## 7. Guardrails (non-negotiable)

- **This is alignment, not redesign.** Do not change layout, grid, spacing scale, component structure, element order, or copy. Only fonts, tokens, the Mermaid output theme, and the default-mode branch change.
- **Pill buttons stay.** `rounded-full` buttons are on-brand; do not change button shape.
- **Primary accent is already correct.** `#c46a2c` is right; do not touch it.
- **Forge scope only.** No coral `#d94f63`, no aqua `#2d6f7e`. Those are sibling brands. Importing them is a failure.
- **Brand firewall.** This is a personal OverKill Hill P³ project. It must not contain or imply Builders FirstSource, BFS, any employer, or any employer color, asset, example, or workflow. Do not add one; flag any you find.
- **No em dashes** anywhere in code, comments, or copy.
- **No AI filler** in copy or comments: not “seamlessly,” “robust,” “powerful,” “effortlessly,” “elevate,” “unleash.”
- **Tailwind v4, no config file.** There is no `tailwind.config.js` and you must not create one. Tokens live in CSS via `@theme inline`. Editing or creating a Tailwind config is wrong.
- **Apply to both apps.** The primary app and `mockup-sandbox` both get items 1 to 9. The Mermaid output fix (10) and default-mode fix (11) apply where those files exist.
- **No new dependencies.**
