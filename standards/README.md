# Standards

The BPMN specification reference files live inside the artifact directory:

```
artifacts/mermaid-diagram-bpmn/standards/
├── BPMN-SPEC-REFERENCE.md                  ← element-by-element compliance map
├── bpmn-beta-standard.md                   ← bpmn-beta DSL standard
├── parser-safety-checklist.md              ← parser safety rules
└── OMG-BPMN-2.0.2-formal-specification.pdf ← full OMG formal spec (local copy)
```
